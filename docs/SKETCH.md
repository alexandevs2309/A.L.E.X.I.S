## Dirección visual

La referencia conceptual es una presencia artificial avanzada:

- centro visual dinámico
- partículas/energía
- estados de actividad
- iluminación y movimiento dependientes del estado real
- voz
- visualización de información contextual
- transición entre avatar, terminal, código, gráficos y mapas

No se busca copiar una interfaz existente. La identidad visual debe ser propia de ALEXIS.

## Regla

El avatar nunca debe ser una simulación vacía. Si ALEXIS está "pensando", "investigando" o "ejecutando", el estado debe provenir del runtime real.
